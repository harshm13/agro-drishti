# Model & Biological Database Directory

Central repository for machine learning weights and agricultural biological solutions:

- `agro_drishti_model.h5`: Trained Convolutional Neural Network (CNN) model weights
- `bio_solutions.json`: 3-step biological treatment and prevention database (Hindi & English)
- `classes.json`: Label mapping dictionary for model predictions
- `agro_drishti_solutions.json`: Compatible alias to bio_solutions.json
